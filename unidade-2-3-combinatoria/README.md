# 🧮 Calculadoras de Análise Combinatória

Estes são os meus projetos da segunda e terceira semana - **Análise Combinatória I e II**. Além de aprender a teoria matemática, estou praticando Python e melhorando minha organização de código! 🐍

## O que tem aqui

### Calculadora de Permutações
- **Fatorial** de números (n!)
- **Permutação simples** P(n) = n!
- **Permutação circular** (n-1)!
- **Permutação com repetição** n!/(a!×b!×...)

### Calculadora de Combinações  
- **Combinações simples** C(n, k) = n! / (k! × (n - k)!)

## Como usar

### Permutações:
```bash
python calculadora_permutacoes.py
```

### Combinações:
```bash
python calculadora_combinacoes.py
```

Ambos têm menus interativos que te guiam pelo processo.

## Conceitos que aprendi

- **Fatorial**: n! = n × (n-1) × ... × 2 × 1
- **Permutação simples**: Arranjos de n elementos distintos
- **Permutação circular**: Arranjos em formato circular  
- **Permutação com repetição**: Arranjos considerando elementos idênticos
- **Combinações simples**: Escolher k elementos entre n, sem considerar ordem
